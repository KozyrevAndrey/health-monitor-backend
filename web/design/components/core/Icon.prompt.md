Inline SVG stroke icon set (Lucide-style, 24px grid / 2px stroke); use for every glyph — the system never uses emoji as icons.

```jsx
<Icon name="alert-triangle" size={16} />
<Icon name="globe" size={14} style={{ color: "var(--text-2)" }} />
```

Type icons by convention: http → `globe`, tcp → `server`, dns → `at-sign`; notifiers: telegram → `send`, email/gmail → `mail`, webhook → `link`.
